## 目录结构说明

```
项目根目录/
├── README.md              ← 你正在看的文件（项目总入口）
│
├── docs/                  ← 【规划文档】AI的"记忆"全部存在这里
│   ├── progress.md        ← 进度跟踪（当前到哪一步了）
│   ├── modules.md         ← 模块清单（拆了哪些章节，各自状态）
│   ├── design-decisions.md← 设计决策（配色、风格、布局，定了就不改）
│   └── brief.md           ← 原始需求/脚本（你最初给的材料）
│
├── assets/                ← 【原始素材】只读，不要改
│   ├── raw/               ← 原始脚本、原始数据文件
│   ├── data/              ← 整理后的数据（CSV/JSON）
│   └── images/            ← 图片素材（AI生成的+你提供的）
│
├── src/                   ← 【开发中】半成品在这里
│   ├── chapters/          ← 各章节的HTML片段/草稿
│   ├── components/        ← 可复用组件（卡片、图表配置等）
│   └── styles/            ← 样式变量、主题配置
│
└── deliverables/          ← 【交付物】最终成品放这里
    └── data-journalism-report/  ← html-report 生成的完整网页
```

## 工作原则

1. **文件 > 对话记忆**：确定下来的东西必须写进文件，不能只在对话里说
2. **一阶段一确认**：每个大阶段完成后，确认了再往下走
3. **渐进式交付**：先出原型，再填充内容，最后调优细节
